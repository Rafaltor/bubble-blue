# Overleaf — BUBBLE-BLUE conference paper

Two files only:

- `main.tex` — manuscript (IEEE conference, 10 pt)
- `refs.bib` — bibliography

## Upload

1. [overleaf.com](https://www.overleaf.com) → **New Project** → **Blank Project**
2. Delete the default `main.tex` Overleaf created
3. Upload `main.tex` and `refs.bib` into the project root (same folder)
4. Menu (top left) → **Compiler: pdfLaTeX**
5. Recompile — the PDF appears on the right

Do not put the files in a subfolder: `\bibliography{refs}` looks in the project root.

Wilfred asked for a PDF attachment rather than a Drive link: Overleaf → **Menu → Download PDF**.
